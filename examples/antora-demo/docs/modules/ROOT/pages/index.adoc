= asciidoctor-kroki-embedded Antora Demo
:kroki-default-format: svg

This Antora page is generated with the local `asciidoctor-kroki-embedded` extension registered through `asciidoc.extensions` in the playbook.
The extension accepts Kroki-compatible diagram blocks and emits safe, inert HTML targets that an Antora UI or host application can hydrate with local renderers.

== Local renderer gallery

All 15 locally supported block names are shown below, including the `dot` and `c4plantuml` aliases.
Expand each source panel to see the input. Diagrams are rendered locally in the browser.
The SvgBob example preserves ASCII art as SVG text; the Excalidraw example uses a basic scene renderer for rectangles, text, and arrows.

== Other accepted block names

The extension also accepts `actdiag`, `blockdiag`, `bpmn`, `dbml`, `ditaa`, `erd`, `nwdiag`, `packetdiag`, `rackdiag`, `seqdiag`, `symbolator`, `tikz`, `umlet`, `structurizr`, `diagramsnet`, and `wireviz`.
These require a host-provided renderer and are not part of the local renderer gallery.

== How this demo is wired

[source,yaml]
----
asciidoc:
  extensions:
    - ./antora-kroki-embedded-extension.mjs
----

[source,js]
----
import { createAntoraExtension } from '../../src/antora.js'

const extension = createAntoraExtension({
  defaultFormat: 'svg',
})

export function register(registry, context) {
  extension.register(registry, context)
}
----
